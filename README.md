Landing estatica para la segunda linea de negocio de ROCIO ESTRELLA como afiliada/patrocinadora independiente de Travorium.

- `index.html`: landing principal.
- `css/style.css`: estilos premium negro/dorado, responsive.
- `js/script.js`: menu movil, header sticky y envio del formulario hacia WhatsApp.

## Verificacion de cumplimiento

- No se usa logo oficial de Travorium.
- La pagina se identifica como sitio personal de afiliada independiente.
- Los CTAs principales llevan a asesoramiento o WhatsApp; el CTA de navbar "Hazte socio" baja al formulario.
- Solo hay un enlace de inscripcion directa a Travorium, en el formulario final.
- Los precios incluidos coinciden con la FAQ oficial consultada: Plata $69.95 + $52.50/mes, Titanio $149.95 + $75/mes, Platino $269.95 + $135/mes.
- Se incluye bloque de transparencia y disclaimer de ingresos.

## Nota importante

Las Politicas y Procedimientos oficiales de Travorium indican que los sitios externos de participantes deben identificarse claramente como independientes, usar solo imagenes/verbiage aprobados y poder modificarse para cumplir politicas vigentes. Antes de publicar, Rocio debe validar esta landing con compliance o documentacion oficial actualizada.
